What does this app do?

Train a simple single-neuron (linear) model on your data and predict the output for a new input.

How it works

  1. Provide 6 values for x (independent variable) and matching 6 values for y (dependent variable).
  2. The model trains for 500 epochs to learn a linear relationship between x and y.
  3. After training, enter a new x to get a predicted y.

Input guidelines

  • Fill all 12 cells (6 x, 6 y); no blanks allowed.
  • Use a varied range of x values to help the model learn better.
  • Wait for the “Training complete” message before making a prediction.
Limitations
  • This model captures linear relations only.
  • Predictions are approximate, not exact.
  • If you see NaN in the result, the model couldn’t train reliably on your inputs. Try:
    • Removing identical or near-identical x values,
    • Avoiding extremely large/small magnitudes,
    • Ensuring each x has a corresponding y.
Technical quick note

Under the hood this is equivalent to fitting a single linear neuron (y = w·x + b) via gradient descent for 500 epochs.
